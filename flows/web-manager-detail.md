# Web manager flow — detail

Copy this shape when a new manager requirement arrives. Map: [web-manager.md](web-manager.md). Role: [Manager](../roles/manager.md). Pixels: [screenshot review](../screenshots/REVIEW.md).

Business Agent. Stack is the React cockpit. Companies they assign land in a rep’s Address Book.

## 1. Cockpit

- **From** — login. Home is `/manager/dashboard`
- **Do** — read KPIs, the map, and the leaderboards
- **Copy** — left sidebar, gradient brand card, six KPI cards, territory map
- **Next** — Find Leads, or Salespeople
- **Stop** — do not rebuild this as an AdminLTE page

## 2. Find Leads and assign

- **From** — cockpit
- **Do** — search, then assign the companies to a rep
- **Copy** — manager Find Leads, including the map circles
- **Next** — the rep’s book, not the manager’s personal book
- **Stop** — this is not the rep Find Leads page. The save spends manager credits

## 3. Salespeople

- **From** — sidebar
- **Do** — open the team, add a rep, or open that rep’s routes
- **Copy** — the salespeople list, then the add form, then the route list
- **Next** — the new rep, or their routes
- **Stop** — do not send the manager through public registration for a rep. A rep created here can receive the day-two review email. That page is the rep’s classic `/reviews/credits`, not a cockpit screen

## 4. Activity, support, settings

- **From** — sidebar
- **Do** — read activity, open a ticket, or change settings
- **Copy** — the matching cockpit page
- **Next** — back to the cockpit
- **Stop** — do not use classic support or classic settings chrome
