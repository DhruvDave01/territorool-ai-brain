# Methods

Six working habits, adapted from [agency-agents](https://github.com/msitarzewski/agency-agents) (MIT, [LICENSE](LICENSE.md)). They say how to check work. They do not say what TerriTool is.

Open [AGENTS.md](../AGENTS.md) first. Then the mini-brain and the still named there. Live code and pixels win over these cards. A method never invents a color, an endpoint, a credit cost, or a new visual language.

| Method | Open when |
|---|---|
| [Render a still](render-still.md) | You must hand back a PNG of a screen |
| [UI finish gate](ui-finish-gate.md) | A screen is about to be called done |
| [Evidence collector](evidence-collector.md) | You need a still of what was actually built |
| [Reality checker](reality-checker.md) | Someone claims the work is production ready |
| [Code reviewer](code-reviewer.md) | A diff needs a review |
| [Minimal change](minimal-change.md) | You are about to edit the live repos |
| [Codebase onboarding](codebase-onboarding.md) | You need to explain a path in the live repos |

The rest of that roster stays out. Do not install it into Cursor for this project. Frontend, Livewire, Flutter, and whimsy agents would overwrite the six mini-brains.
