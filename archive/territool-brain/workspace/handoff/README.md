# Handoff — where Claude Code and Codex meet

**Codex runs, Claude checks** (owner decision, 2026-09-16). This folder is the only place Codex writes.

```
workspace/handoff/<YYYY-MM-DD>-<slug>/
  request.md    written by Claude Code — exact commands, scope, what NOT to touch
  result.md     written by Codex       — per command: exit code, output tail, verdict
  *.json        machine-readable run reports (e.g. the API-contract runner's --json output)
```

## Rules

**For `request.md`** — every command is verbatim and runnable, with its working directory stated. Only
commands verified to exist (`node tools/doctor.js`). Nothing that spends credits, purchases, syncs a CRM
or touches production is ever written into a request.

**For `result.md`** — exit codes, not opinions. A command that did not run is `NOT RUN`, never inferred
from another result. No credentials or tokens: the suites read `.local/test-accounts.md` themselves and
redact their own output, so there is never a reason to paste one here.

**Capture:** when Claude reads a `result.md`, it records what the run established in `brain/memory/` (`node tools/memory.js new …`, `origin: ai-loop`, source = the `result.md` path). Anything Codex learned that isn't captured is lost after the session.

**Codex writes nothing outside this folder.** `brain/**` has a single writer — Claude Code — because the
Obsidian vault and the shared graph are two renderings of one index, and a second writer drifts them
apart until someone re-runs `tools/brain-sync.js`.

Full contract: `brain/context/tooling.md` §3.
