# 01 - Product Context

Create `product.md` here answering:
- What does Territool do, in 5 sentences?
- Who uses it? List every user role and what each can do.
- Mobile app vs web app: who uses which, and what overlaps?
- What is the single most important flow in the product?
- What are you building next (next 3 months)?
- Any domain vocabulary I must use correctly (job, site, crew, asset, tool, etc.)
