# 02 - Mobile (React Native)

After adding files, tell Claude "new mobile screenshots added". Claude then:
1. runs `node tools/sync-design-assets.js`, which copies them into the brain's design library (`brain/assets/`);
2. matches each capture to its screen, code and flow (`brain/context/flows.md`);
3. uses them in design audits and test cases.

## screenshots/

- **Naming:** `<flow>_<step>_<screen-name>.png`, for example `auth_01_splash.png`, `auth_02_login.png`, `auth_03_otp.png`.
- **Many screenshots?** Put one subfolder per flow: `screenshots/auth/`, `screenshots/job-create/`, `screenshots/settings/`.
- **Include states:** empty, loading, error, long-content. Those are where design consistency actually breaks.

Optional, to help the brain:
- **Platform subfolder:** `screenshots/ios/…` or `screenshots/android/…`. Android captures are the biggest gap today.
- **Flow ID in the name:** from `brain/context/flows.md`, e.g. `f15_01_bulk-contact-review.png`.
- **Unnamed files** (`IMG_1234.PNG`) are fine too. Claude identifies the screen by looking at them.

Library copy: `brain/assets/screenshots/mobile-owner/`.

## videos/

- **Naming:** `<flow>_full.mp4`. A screen recording of you walking the flow end to end.
- Narrate if you can, or add a matching `<flow>_full.md` with timestamps.

Library copy: `brain/assets/videos/mobile-owner/`.

## frames/

**Leave empty.** Claude Code extracts frames from your videos here via ffmpeg. Library copy: `brain/assets/screenshots/mobile-owner-frames/`.

## notes/

Free-form: anything about a screen that a screenshot won't show (gestures, animations, offline behaviour, permissions, deep links). Library copy: `brain/assets/docs/mobile-owner-notes/`.

Helpful to mention, in a note or the file name:
- **App build and device:** e.g. "iOS 42.31 (1), iPhone 15".
- **Environment:** staging (preferred) or production.
- **Role used:** Sales Agent or Business Sales Agent. Name the role only; never write passwords.

## Please avoid

- Real customer personal data from production. Use staging data or blur it.
- Anything showing passwords, tokens or API keys.

## Note

`Assets/` in this folder is a copy of `Design-Brain/03-Assets` (checked 2026-09-15: all 125 files are already in the brain library). New captures go in `screenshots/`, `videos/` and `notes/` above.
