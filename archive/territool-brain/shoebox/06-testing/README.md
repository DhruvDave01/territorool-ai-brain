# 06 - Testing

## existing-tests/
Copy a representative sample of tests you already have (both platforms).
If you have none, create `NONE.md` saying so.

## formats/
The output format you want test cases in. Drop a real example:
an .xlsx, a Notion export, a Jira/TestRail CSV, or a markdown table.
The brain will match this format exactly.

## codex/
Create `codex-setup.md` answering:
- Which Codex product exactly, and how do you invoke it?
- Does it run in the terminal, an IDE, a web UI?
- Can it execute commands / run a simulator / drive a browser?
- Do you want the brain to WRITE test code for Codex to run,
  or write natural-language test plans for Codex to execute?
- What device/emulator/browser targets?
