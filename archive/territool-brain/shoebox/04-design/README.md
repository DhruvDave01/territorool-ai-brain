# 04 - Design System

## tokens/
Create `tokens.md` (or drop the real files) with:
- Colour palette: every colour + its semantic name + where it's used
- Type scale: family, sizes, weights, line heights
- Spacing scale
- Border radii, shadows/elevation
- Icon set + size rules
- Component sizes: button heights, input heights, card padding

If mobile and web currently DIFFER, write both and mark the differences.
Do not clean them up first - I need the real, messy truth.

## figma/
Link in `figma.md`, plus PNG exports of key frames if the file is private.

## references/
Apps/sites whose design you want to move toward. Screenshots + one line
each on what specifically you like about it.
