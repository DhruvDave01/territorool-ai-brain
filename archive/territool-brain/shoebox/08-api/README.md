# 08 - API

Whatever you have:
- OpenAPI/Swagger spec
- Postman collection export
- Route list: `php artisan route:list --json > routes.json`
- Or a hand-written `endpoints.md`

Also note: auth mechanism, token/refresh behaviour, error response shape,
pagination convention, file upload convention.
