1. `node tools/memory.js sync`. It:
   - captures new commits since LAST-SYNC;
   - lists uncommitted work (never ingests or edits it);
   - records environment pointers;
   - marks outdated entries NEEDS-REVALIDATION;
   - rewrites LAST-SYNC;
   - rebuilds `_generated/`.
2. Read `brain/memory/_generated/CHANGES.md` and `FRESHNESS.md`. Classify every meaningful change as:
   DOCUMENTED+CURRENT · DOCUMENTED+CHANGED · NEW+UNDOCUMENTED · REMOVED+STILL-DOCUMENTED · RENAMED/MOVED ·
   POSSIBLY-OUTDATED · CONFLICTED · UNKNOWN · NEEDS-REVALIDATION.
3. For a disappeared file, use `git log --follow` / `git diff -M` to tell deleted from renamed. Record a
   `deprecation` entry old → new. Never delete knowledge.
4. `node tools/memory.js render && node tools/memory.js lint --strict && node tools/brain-sync.js --quiet`.
5. Report:
   - what changed, what was verified, what stays unknown
   - open conflicts, and what needs a human
   - the result: COMPLETE, PARTIAL, FAILED or BLOCKED, with the reason

Never report a sync that did not run.
