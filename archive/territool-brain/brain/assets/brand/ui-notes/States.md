# UI states

Documented from code + Archive 2. Do not assume a screen has a skeleton if none exists.

## Cross-cutting

| State | How it appears |
| --- | --- |
| Default | Gradient header + curved body + white cards |
| Pressed | AppButton darkens ~12%; tiles/press overlays `pressDarkOverlay` / `pressWhiteOverlay` |
| Disabled | Gray CTA (`IMG_4565` Next step); gray Email chip on View Contact (`VID3 v3_007_56s`); socials gray on More Info (`IMG_4578`) |
| Loading overlay | Dashboard dim + TT spinner “LOADING.” / “Loading credits…” (`VID3 v3_000_0s`) |
| Inline spinner | Lists “Loading lists…”; Contacts tab; company pager “1/n” spinner (`VID3 x3_t6s`); map “Loading route on map…” |
| Empty | Gray centered copy (contacts, activity, upcoming) |
| Success toast | Green/top — company created, contact saved, visited |
| Error toast | “Please provide position.”; partial company add; API errors |
| Validation | Inline/toast before submit; Report submit disabled until reason (`IMG_4580`) |
| Offline | CustomFooter top toast “No Internet Connection!!” |
| Permission | Location for Find Leads / maps; camera/photos for Scan Card & QR |
| Session expired | AppConfirmModal → Login (no capture) |
| Crash | AppCrashFallback (no capture) |

## Screen-specific (captured)

| Screen | States seen |
| --- | --- |
| Dashboard | Empty Upcoming; Recent with rows; Invalid Date vs valid date; loading credits; unread badges |
| AI Find Leads | Form disabled Next; keyboard; search % + source logos; map pins; selected list; confirming %; add-to-route; results with contact chips |
| Create Route/List | All vs Selected; Next vs Submit; name modal; partial-save toast |
| Publish | Plotting 5%; Preparing Route + fuel copy |
| Company | Empty contacts/activity; with contact; Find Contacts disabled while busy; Mark vs Add To; pager |
| Find Contacts | Checking Apollo; Still working; Taking longer; empty Done; people + Show Contacts; saved check |
| Scan Card | Camera/Gallery only; preview + Review details + Copy all |
| Filter | Partial sheet + Scroll for more; A-Z selected |
| QR | Dark viewfinder, “Align code within the frame” |
| Calendar | Other day selected vs Today (blue 11 vs green Today label) |
| Login | Default (no error still) |
