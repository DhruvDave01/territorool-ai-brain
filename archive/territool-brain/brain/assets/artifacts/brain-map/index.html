Check 1

Referral invites, a change across both repos

Would block · 5 misses fixed

Web 682e68dc + mobile d15d5a2, 1 Jul 2026

Caught

  • JWT parsed inside the controller (W6, automatic ×2)
  • Literal font size (M8, automatic)
  • New service with no tests (W8)
  • Touches login/registration: BLOCKER regression forced
  • App requires 10-digit phone, API accepts any

Missed → gate added

  • "Invite sent!" but nothing is sent; copy fixed twice next day (CG-A10)
  • Reward can apply from 4 paths, no-op without a credit row (CG-A9)
  • All users loaded to match a phone (CG-W11)
  • Errors shown in success green (DG-B11)
  • Invite link lands on production register (QG-6)
Check 2

A bug that reached production

Caught by static gate

"bulk contact production error fix" fe1cfde2, introduced by 2acec7fa

A FullEnrich batch call was added to frozen Helper.php without error handling. W7-frozen fails that commit automatically, forcing a service with tests. Staging tests alone wouldn't reproduce a provider failure, so the gate now demands provider-failure cases and a six-point external-call rule.

  • Secret detector extended: the provider key was a hardcoded config fallback
  • False positive fixed: PHPDoc shapes no longer flagged as PHP 8
  • Still in the code today: the key fallback at 5 sites (reported, not changed)
