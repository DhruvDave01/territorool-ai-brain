# brain-score counted a PASS verdict on any line of a report instead of the first

## What

PASSING was tested against the whole file; FEATURE_SCORE_MODEL.md says only the first Verdict line counts. A report that quotes an older PASS further down would have scored +20.

## Why it matters

The F01 report keeps its hand-written text (with an old PASS-WITH-NOTES verdict) as an appendix.

## Evidence

tools/brain-score.js (self-test "only the first verdict line counts")

## Implication for future work

Any scorer that parses reports must read the first verdict line only; historical verdicts kept in a report must be prefixed so they cannot match.
