# The brain graph gets a hub-and-spoke view alongside the full graph

## What

The owner found the main Obsidian graph unreadable next to a senior's hub-and-spoke vault. The busy look came from display settings (about 2,250 attachments and every tag drawn as dots) and from dense cross-links. The main vault now hides tags, attachments, code, screenshots and commit records by default, applied once per defaults version. tools/hub-map.js draws the same index as a tree (one parent per note) in views/hub-map/ and behind the page's Hub map button.

## Why it matters

A picture a person can read, without cutting the links the brain uses to answer questions.

## Evidence

USER SAID 2026-09-17 · tools/hub-map.js · brain/context/tooling.md §4c

## Implication for future work

Never delete notes or links to make the graph look simpler: change the view (tools/lib/hubs.js, graph defaults) instead. views/hub-map/ is generated and ignored by the main vault; hub-data.js is only used when it matches graph-data.js.
