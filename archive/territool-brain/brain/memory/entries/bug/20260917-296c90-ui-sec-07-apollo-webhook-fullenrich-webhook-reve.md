# UI-SEC-07 — apollo-webhook, fullenrich-webhook/*, revenue-subscription-update and revenuecate-success verify no signature…

## What

API V2 webhooks (public): apollo-webhook, fullenrich-webhook/*, revenue-subscription-update and revenuecate-success verify no signature or secret. A forged RevenueCat event can create or renew a paid Subscription for any user id; a forged Apollo call can overwrite contact phone numbers for any user/company

## Why it matters

Severity Critical. User impact: free paid plans; data tampering

## Evidence

WebhookController.php:26-45, 79-130; AuthController.php:502-540 (EV-C13). Not called

## Implication for future work

Not fixed (application code frozen during brain work). Improvement: verify the RevenueCat Authorization header and the Apollo/FullEnrich signatures; refuse unsigned calls. Investigate next: check production logs for unexpected webhook callers
