# KG-UI8 — Delete-contact sheet survives navigation. The success path of deleteContact() navigates away (goBack() or nav…

## What

Delete-contact sheet survives navigation. The success path of deleteContact() navigates away (goBack() or navigate("ListCompany")) but never resets deleteContact, so the modal stays mounted over the next screen, still saying "will be deleted from this company". The only four resets are dismissal handlers (backdrop, swipe, two buttons) — none fire on success. Root cause verified in code.

Pre-existing known gap on F13, F12; the QA gate classifies it instead of failing (known-fragile §5).
