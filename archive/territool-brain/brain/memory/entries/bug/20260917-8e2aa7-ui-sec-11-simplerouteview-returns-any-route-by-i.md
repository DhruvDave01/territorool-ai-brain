# UI-SEC-11 — simplerouteview returns any route by id to any logged-in user: the Sales Agent's token received the Business…

## What

API V2: simplerouteview returns any route by id to any logged-in user: the Sales Agent's token received the Business Sales Agent's route with all its stops. Route ids are sequential, so every user's routes (companies, addresses) are enumerable

## Why it matters

Severity High. User impact: another account's territory and customer list exposed; the customer MCP inherits it

## Evidence

Runtime 2026-09-16 (TC-F09-002, EV-A14): owner and non-owner got identical payloads (route_details[4]). The only owner check in the action guards the is_route_open write

## Implication for future work

Not fixed (application code frozen during brain work). Improvement: scope the read to the owner (or to a share) (S3.8). Investigate next: advancerouteview, getuseractiveroute, getroutedata and the list views
