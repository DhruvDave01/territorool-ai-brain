# Safe validation tests only where the controller refuses before any write

## What

Write endpoints get an empty-body validation case only after reading that a required-field check returns before any insert/update: createList, addcontact, addnote, addticket, updateuserstatus, scan-qr-code, mobileregistration (without a password).

## Why it matters

It lets validation be covered on a shared staging without creating data.
