# UI-UX-08 — Manager portal renders DM Sans and Space Grotesk, not DIN only (D-DS3)

## What

On the manager portal, document.fonts shows DM Sans and Space Grotesk loaded and 134 visible text elements computed in DM Sans on /manager/dashboard.

## Why it matters

D-DS3 (DIN only, everywhere) is an owner decision; the portal breaks it on every screen.

## Evidence

Runtime measurement 2026-09-17 with the web visual helper; `repos/web/public/css/manager-portal-responsive.css:593`.

## Implication for future work

Visual QA on portal screens records this as known gap UI-UX-08, not a new failure; new portal code must use DIN and the web tokens.
