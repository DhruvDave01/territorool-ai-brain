# Device frames

Mobile UI pictures sit inside one of these phones. The sheet is [iphone-frames.png](iphone-frames.png): orange, navy, silver, left to right.

The live device still wins over this sheet. Dashboard copies the black phone in the 1:45 still: a small island in the status bar, time on the left, radio icons on the right. Leave a gap under the island before the logo. Inset every control from the corner radius so a label such as Calendar is complete. Do not use the white frame if it makes a second, larger island.
