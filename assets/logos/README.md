# TerriTool logos

The mark is the isometric TT cube. Do not redraw it. Usage: [public site](../../product/public-site.md).

The in-app cube is in [images/mobile](../images/mobile/README.md): `TerriTool_logo_NEW.jpg` on white, `TT_NO_BG.png` on black.

| File | What it is |
|---|---|
| [territool-mark-blue.png](territool-mark-blue.png) | Small cube export, blue on white. |
| [territool-wordmark-black.png](territool-wordmark-black.png) | Cube plus TERRITOOL, 208 × 50. Despite the name, it is white on a transparent background, so it disappears on white. Pixels checked 2026-09-28. |
| [territool-wordmark-blue.png](territool-wordmark-blue.png) | Cube plus TERRITOOL, 1024 × 222, blue on a black canvas. |

There is no dark lockup for a white page. Put the white file on a `#124ac6` or black bar, as the Bulk Contacts PDF of 2026-09-28 does, or use the cube alone.
