# Feature flow sheets

One PNG per module and surface. Each sheet is the full flow of that feature: numbered steps, the shipped still for each step, a one-line caption, and the rules and strings that module depends on. Rendered 2026-09-23 from the stills in [screenshots](../../screenshots/REVIEW.md). The two "proposal" sheets under 05 use the rendered stills in [features](../05-Find-Leads.md#proposal-2026-09-22--chat-flow-with-one-map-circle), not shipped screens.

Pixels win. If a caption and a still disagree, the still is right. The filename of a still is a capture time, not a layout name.

## Coverage notes

- Mobile-only modules have no web sheet where the web has no page for it (06 web is the two /recent grids; 10, 13 are web only; 16 and 17 are web only by design; 19 has no screen of its own, so its sheet is the email, the pending state, and the HQ tables).
- Every step image is a shipped still. No screen was redrawn. Very tall web pages are shown from the top and say so in the caption.
- To pick a still for new UI, open the sheet for that module, find the step, then open the original file named in [_build/manifest.js](_build/manifest.js).

## Rebuild

```bash
node features/flows/_build/build.js            # all sheets
node features/flows/_build/build.js 07-routes-mobile   # one sheet
```

Edit [_build/manifest.js](_build/manifest.js) to add a step: title, caption, still path. The renderer reads every still size with sips, lays the cards out, and screenshots the page with headless Chrome at 2x. Fonts come from [assets/fonts/web](../../assets/fonts/web).
